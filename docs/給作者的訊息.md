# 給 QIYUN 的私訊

## 完整版

你好，我是林亞澤，同一屆創作者挑戰的參賽者。

《第九號病人》我很喜歡。六個人三張床那一問、龍傲天問「為什麼對著空氣揮拳」、還有最後孤兒院裡的八號跟九號——看完之後我動手做了個東西。

我把整部作品整理成一個可以從頭讀完的網站，九個結局的圖與走法也列了一份：

https://yazelin.github.io/patient-9-guide/

做這個的理由只有一個：好作品應該更容易被看見。你的作品要一直點、一直選，而且選錯就死，所以有些人不會走到最後那段回憶。這個站讓他們也看得完，然後回去玩你的原作。整站十四個連結指回 Larch，首屏第一顆按鈕就是「去 Larch 玩原作」，最上面有一條防雷帶，寫明整頁都是劇透、還沒玩的先去玩。作者頁與挑戰賽專區也都連上了。

幾件先跟你說清楚的事：

內容是從市集的公開發佈快照整理的，你的文字一個字都沒有改。插圖放的是縮到寬一千的副本，因為原檔一張兩 MB、五十幾張超過一百 MB，不想讓讀者跟你的圖床一起受累，原始網址都留在檔案裡。故事、角色與全部插圖的版權是你的，網站與原始碼都寫明了這件事。

你說完整攻略九月二十號會放在留言區，我已經在站上請大家去看你那一份。你貼出來以後我補一個直接連過去的連結。

如果有任何一段你不想被這樣放出來，想改寫法、想換圖，或是想整個撤掉，跟我說一聲，我照做。反過來說，你想拿這個站去用——放進宣傳、丟給朋友、貼在自己的留言區——都不必問我。

最後，祝你比賽順利。結局那張「你以為 009 的故事已經結束了嗎」我看到了，完整版做出來記得說一聲。
